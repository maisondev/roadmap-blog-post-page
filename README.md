# Blog Post Page

Uma página de blog post semântica construída com HTML puro, seguindo as melhores práticas de acessibilidade e web standards.

## 🎯 Objetivo

Este projeto demonstra como criar uma página de blog post utilizando HTML semântico correto, sem dependências de CSS ou frameworks, focando em:

- **Acessibilidade** - Estrutura adequada para leitores de tela
- **Semântica** - Uso correto de tags HTML para comunicar significado
- **SEO** - Estrutura otimizada para mecanismos de busca
- **Manutenibilidade** - Código claro e fácil de entender

## 📋 Requisitos Implementados

✅ **Estrutura de Página**
- `<header>` com navegação
- `<main>` com conteúdo principal
- `<article>` para o artigo de blog
- `<footer>` com informações adicionais

✅ **Headings Semânticos**
- Um único `<h1>` para o título do post
- `<h2>` e `<h3>` para subseções
- Sem pulos de níveis

✅ **Elementos de Texto**
- `<p>` para parágrafos
- `<ul>` para listas não ordenadas
- `<ol>` para listas ordenadas
- `<blockquote>` para citações
- `<cite>` para fontes de citações
- `<code>` e `<pre>` para código

✅ **Ênfase Semântica**
- `<em>` para ênfase
- `<strong>` para importância

✅ **Links Descritivos**
- Todos os links possuem texto descritivo
- Sem "clique aqui" ou "leia mais"

✅ **Imagem Semântica**
- `<figure>` para envolver a imagem
- `<img>` com `alt` descritivo
- `<figcaption>` para legenda

✅ **Metadados**
- `<title>` apropriado
- `<meta charset="UTF-8">`
- `<meta viewport>` para responsividade
- Meta description resumindo o post
